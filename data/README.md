# Data Directory Guidelines

This directory houses documentation and sample datasets for development and testing.

## Important Policies

1. **Original Source Data**:
   - The historical sales dataset referenced in earlier iterations is `Superstore.csv`.
   - Never assume or claim that a mock dataset is the original historical dataset.
   - Real customer data and sensitive production exports must **never** be checked into version control.

2. **Synthetic Data**:
   - For local development and testing, synthetic datasets generated by automated seed scripts or CSV generators must be clearly marked as `synthetic_sample_sales.csv`.
   - Any synthetic dataset should include required headers:
     `Row_ID, Order_ID, Order_Date, Ship_Date, Ship_Mode, Customer_ID, Customer_Name, Segment, Country, City, State, Postal_Code, Region, Product_ID, Category, Sub_Category, Product_Name, Sales, Quantity, Discount, Profit`

3. **Multi-Tenant Import Rules**:
   - Imported records must **always** be explicitly mapped to an active `CompanyID` (and optionally `StoreID`).
   - The staging table `RawSalesData` serves as a validation buffer before transactional normalization.
   - Ambiguous or unassigned CSV records must be rejected with descriptive error reporting.
